# Panduan Pengajar Rapor Digital

Panduan ini ditujukan untuk guru dengan role Pengajar.

## A. Peran Pengajar

Pengajar bertugas mengelola pembelajaran dan nilai untuk kelas/mapel yang diajar.

Tugas utama:

- Melihat daftar pembelajaran.
- Melengkapi Lingkup Materi dan Tujuan Pembelajaran.
- Menginput nilai manual.
- Menggunakan template nilai Excel.
- Upload nilai Excel satu mapel atau multi-sheet.
- Melihat preview nilai.

## B. Login dan Pilih Role

Jika guru memiliki lebih dari satu role, pilih role Pengajar setelah login.

Role memengaruhi menu yang tampil:

- Role Pengajar untuk input nilai dan pembelajaran.
- Role Wali Kelas untuk absensi, catatan, dan rapor kelas.

Jika halaman menampilkan peringatan role, pilih role yang sesuai lalu buka ulang halaman.

## C. Dashboard Pengajar

Dashboard menampilkan ringkasan sesuai data yang tersedia, misalnya:

- Jumlah siswa.
- Pembelajaran/mapel yang diajar.
- Progres nilai.
- Notifikasi.
- Pusat Bantuan.

Gunakan tombol Informasi untuk membaca notifikasi yang berkaitan dengan pekerjaan Anda.

## D. Data Pembelajaran

Data Pembelajaran berisi daftar kelas dan mata pelajaran yang diajar.

Status yang mungkin muncul:

- Siap: LM/TP lengkap dan input nilai dapat digunakan.
- Belum lengkap: ada Lingkup Materi yang belum memiliki Tujuan Pembelajaran.

Jika ada ikon peringatan, klik untuk melihat alasan. Biasanya peringatan muncul karena TP belum lengkap.

## E. Lingkup Materi dan Tujuan Pembelajaran

Lingkup Materi atau LM adalah kelompok/topik materi. Tujuan Pembelajaran atau TP adalah tujuan pembelajaran di dalam LM.

Contoh:

- LM: Bilangan Cacah.
- TP: Siswa mampu membaca bilangan sampai 100.

Template nilai Excel membutuhkan LM/TP lengkap. Jika belum lengkap, download template dapat terkunci.

### Salin LM/TP dari Kelas Paralel

Jika kelas paralel memiliki mata pelajaran yang sama dan sudah lengkap, opsi salin LM/TP dapat muncul.

Jika checkbox salin LM/TP dicentang:

- Lingkup Materi manual boleh kosong.
- Sistem menyalin LM dan TP dari sumber aman.
- Nilai siswa tidak ikut disalin.

Jika checkbox tidak dicentang:

- Isi LM manual seperti biasa.

## F. Input Nilai Manual

Langkah umum:

1. Buka Data Pembelajaran.
2. Klik aksi input/lihat nilai pada kelas-mapel yang siap.
3. Isi nilai TP.
4. Isi nilai LM jika tersedia.
5. Isi nilai tes dan non-tes jika ada.
6. Isi Nilai Sumatif Akhir Semester jika sudah ada.
7. Klik Simpan.

Catatan penting:

- Nilai Sumatif Akhir Semester bersifat optional.
- Nilai kosong tidak dihitung sebagai 0.
- Nilai 0 tetap dianggap nilai asli.
- Jangan keluar dari halaman sebelum klik Simpan jika ada perubahan.

## G. Download Template Nilai Excel

Pengajar dapat download template:

- Satu pembelajaran.
- Semua template siap.

Syarat:

- LM/TP lengkap.
- Pembelajaran berada dalam kelas/mapel yang diajar.

Perhatian:

- Jangan mengubah kolom tersembunyi.
- Jangan mengubah struktur sheet.
- Isi hanya kolom nilai.
- Gunakan template dari aplikasi, bukan file buatan manual.

## H. Upload Nilai Excel

Upload satu template digunakan untuk memuat nilai ke form input.

Langkah umum:

1. Download template nilai.
2. Isi nilai di Excel.
3. Buka halaman input nilai.
4. Klik Import Nilai Excel.
5. Upload file.
6. Cek nilai yang masuk ke form.
7. Klik Simpan agar nilai masuk database.

Nilai belum tersimpan hanya karena file berhasil dimuat. Nilai baru tersimpan setelah tombol Simpan diklik.

Error umum:

- File bukan template dari aplikasi.
- Kelas tidak cocok.
- Mata pelajaran tidak cocok.
- Nilai di luar 0-100.
- Struktur template berubah.

## I. Upload Semua Nilai Multi-Sheet

Fitur ini digunakan untuk workbook yang berisi beberapa sheet pembelajaran.

Langkah umum:

1. Klik Download Semua Template Siap.
2. Isi nilai di setiap sheet.
3. Klik Upload Semua Nilai Excel.
4. Upload workbook.
5. Cek preview per sheet.
6. Klik Simpan & Lanjut untuk menyimpan sheet yang sedang dibuka.
7. Lanjutkan sampai semua sheet selesai.

Perhatian:

- Simpan dilakukan per sheet.
- Sheet yang belum diklik Simpan & Lanjut belum masuk nilai.
- Keluar sebelum menyimpan sheet berikutnya tidak menghapus sheet yang sudah disimpan.
- Tidak ada mode Simpan Semua.

## J. Preview Nilai

Icon mata digunakan untuk melihat preview nilai.

Preview mengikuti nilai yang sudah tersimpan. Admin menentukan jenis rapor yang dibuka untuk Wali Kelas, tetapi Pengajar tetap mengelola nilai pada pembelajaran aktif.

## K. Search/Filter

Beberapa halaman mendukung search/filter tanpa reload penuh.

Tips:

- Ketik kata kunci lalu tunggu sebentar.
- Gunakan Filter untuk mempersempit data.
- Jika data tampak hilang, klik Reset Filter atau kosongkan pencarian.

## L. Notifikasi

Tombol Informasi membuka notifikasi.

Fitur:

- Tandai semua dibaca.
- Hapus notifikasi sendiri jika tersedia.
- Filter notifikasi.

Notifikasi nilai dibuat per kelas/mapel, bukan per siswa, agar tidak menumpuk.

## M. Troubleshooting Pengajar

| Masalah | Solusi Aman |
| --- | --- |
| Tombol download template tidak aktif | Lengkapi LM/TP terlebih dahulu. |
| Upload Excel gagal | Pastikan file berasal dari template aplikasi dan kelas/mapel cocok. |
| Nilai tidak berubah | Pastikan sudah klik Simpan setelah upload atau edit manual. |
| Salah role | Ganti role ke Pengajar. |
| Data pembelajaran tidak muncul | Hubungi Admin untuk cek assignment guru/mapel/kelas. |
| Filter/search membuat data hilang | Reset filter atau kosongkan pencarian. |
| LM/TP belum lengkap | Buka Data Mata Pelajaran dan lengkapi TP pada setiap LM. |
