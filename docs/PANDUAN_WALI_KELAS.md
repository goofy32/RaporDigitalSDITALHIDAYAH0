# Panduan Wali Kelas Rapor Digital

Panduan ini ditujukan untuk guru dengan role Wali Kelas.

## A. Peran Wali Kelas

Wali Kelas bertugas mengelola data pendukung rapor untuk kelas yang menjadi tanggung jawabnya.

Tugas utama:

- Melihat daftar siswa.
- Mengisi absensi.
- Mengisi catatan siswa.
- Melihat dan download rapor.
- Memantau DOCX/PDF.

## B. Login dan Pilih Role

Jika guru memiliki lebih dari satu role, pilih role Wali Kelas setelah login.

Role Wali Kelas hanya menampilkan kelas yang menjadi tanggung jawab guru tersebut. Jika tidak ada kelas, hubungi Admin.

## C. Dashboard Wali Kelas

Dashboard dapat berisi:

- Ringkasan siswa.
- Ringkasan absensi.
- Ringkasan mata pelajaran.
- Ekstrakurikuler.
- Notifikasi.
- Pusat Bantuan.

Gunakan dashboard untuk memantau kesiapan kelas sebelum mencetak rapor.

## D. Daftar Siswa

Daftar siswa menampilkan siswa pada kelas Wali.

Fitur:

- Search nama, NIS, atau NISN.
- Filter jika tersedia.
- Aksi siswa seperti absensi, catatan, atau rapor.

Jika siswa tidak muncul, cek apakah search/filter masih aktif. Jika tetap tidak muncul, hubungi Admin untuk cek kelas dan tahun ajaran aktif.

## E. Absensi

Absensi masuk ke rapor.

Data yang umum diisi:

- Sakit.
- Izin.
- Tanpa keterangan.

Langkah:

1. Buka menu Absensi.
2. Isi jumlah absensi tiap siswa.
3. Klik Simpan.
4. Pastikan pesan sukses muncul.

## F. Catatan Siswa

Catatan siswa adalah catatan umum Wali Kelas yang masuk rapor.

Langkah:

1. Buka siswa atau menu catatan.
2. Isi Catatan Umum.
3. Perhatikan batas karakter jika tersedia.
4. Klik Simpan Catatan di kanan atas.

Jika catatan tidak berubah, pastikan tombol Simpan Catatan sudah diklik.

## G. Rapor UTS/UAS

Wali Kelas hanya dapat mengakses jenis rapor yang dibuka oleh Admin.

Penting:

- UTS dan UAS berada pada semester aktif.
- UAS bukan berarti semester Genap.
- Jika Admin belum membuka UAS, UAS tidak tersedia.
- Jika template belum aktif, aplikasi menampilkan pesan agar menghubungi Admin.

Contoh:

- Semester aktif: Ganjil.
- Admin membuka: UAS.
- Wali Kelas mengakses: UAS semester Ganjil.

## H. Download DOCX/PDF

DOCX biasanya dapat diunduh langsung jika template tersedia.

PDF dibuat oleh sistem melalui proses background. Jika PDF sedang disiapkan:

1. Tunggu beberapa saat.
2. Cek kembali status.
3. Jika terlalu lama, hubungi Admin atau teknisi.

PDF yang terlalu lama biasanya berkaitan dengan queue worker, Supervisor, LibreOffice, atau server maintenance mode.

## I. Notifikasi

Tombol Informasi membuka notifikasi.

Fitur:

- Tandai semua dibaca.
- Hapus notifikasi sendiri jika tersedia.
- Filter notifikasi.

Menghapus notifikasi tidak menghapus data siswa, rapor, atau nilai.

## J. Troubleshooting Wali Kelas

| Masalah | Solusi Aman |
| --- | --- |
| Siswa tidak muncul | Reset search/filter, lalu hubungi Admin jika tetap kosong. |
| Tidak bisa akses siswa | Pastikan siswa berada di kelas Wali pada tahun ajaran aktif. |
| Rapor belum tersedia | Cek jenis rapor yang dibuka Admin. |
| Template belum tersedia | Hubungi Admin untuk mengaktifkan template. |
| PDF belum siap | Tunggu worker memproses atau hubungi Admin jika terlalu lama. |
| Catatan/absensi belum tersimpan | Pastikan tombol Simpan sudah diklik. |
| Filter/search aktif | Reset filter atau kosongkan pencarian. |
